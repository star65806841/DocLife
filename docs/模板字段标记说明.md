# 模板字段标记说明

给模板单元格填「占位符」，程序打开表格时会自动替换成当前工程/节点信息，无需在每张表里手抄一遍。

## 1. 可用的占位符

| 占位符 | 替换成 | 来源 |
|---|---|---|
| `#projectName` | 工程名称 | 工程信息（未填则用工程显示名） |
| `#ownerUnit` | 建设单位 | 工程信息 |
| `#constructionUnit` | 施工单位 | 工程信息 |
| `#designUnit` | 设计单位 | 工程信息 |
| `#supervisionUnit` | 监理单位 | 工程信息 |
| `#unitName` | 单位工程名称 | 当前表格往上最近一层「单位工程」 |
| `#subName` | 分部工程名称 | 最近一层「分部工程」 |
| `#itemName` | 分项工程名称 | 最近一层「分项工程」 |
| `#sheetName` | 表格名称 | 当前表格节点名 |
| `#date` | 当天日期 | 打开/刷新当天（yyyy-MM-dd） |

## 2. 怎么写

- 占位符可以放在单元格文本的**任意位置**，也可以和普通文字混写：
  - `工程名称：#projectName`
  - `#unitName 路基土方检验批`
- 一个单元格可以放多个：`#itemName（#date）`
- 大小写敏感，必须是表里的拼写。
- 未知的 `#xxx` 会**原样保留**，不会报错。
- 含占位符的单元格会被自动标成「工程信息」：**黄色底、只读**；要改的话双击解锁（只影响本工程的这份表，不动模板）。

## 3. 显示与刷新

- 打开表格时替换成实际值；关闭再打开也一样。
- 工程信息或节点名称改了之后，点表格上方的 **「刷新信息」** 重新替换。
- 数据库里**始终保存占位符原文**（`sheet_cells.value`），替换只发生在显示层：
  - 好处：节点改名、工程信息修改后，刷新即可，不会留下过期值；
  - 打印/导出时同样先替换再输出。
- 模板预览里显示的是占位符原文（因为预览不属于任何工程）。

## 4. 转换流程

1. 在 Excel 里按上面的规则填好占位符；
2. 先检查一遍（可选）：
   ```bash
   python tools/check_template_tokens.py resources/data/examples
   ```
   会列出每个文件用到的占位符、以及不认识的 `#xxx`；
3. 生成模板库：
   ```bash
   python build_catalog_db.py --collection examples
   ```
4. 用生成的 `.dlt` 覆盖运行目录下的模板库，重启程序。

> 注意：`check_template_tokens.py` 只读 `.xlsx`；老的 `.xls` 需要先另存为 `.xlsx`。

## 5. 数据库要不要加字段？

**目前不需要**：

- 模板库：占位符就是普通文本，`sheet_cells.value` 原样保存；
- 工程库：复制模板时已有 `cell_role` 列，含占位符的格子标为 `project`。

只有下面两种情况才需要加 `field_key` 列：

- 要把某个格子和字段**强绑定**（不靠文本里的 `#`，而是由程序按 key 填）；
- 要做字段级的导出/校验（例如导出成 XML 时按 key 取值）。

真要做时只需在 `sheet_cells` 加一列 `field_key TEXT`，模板转换时写入，运行时优先用它取字段。

## 6. 常见问题

- **替换后是空的？** 对应字段没有值（比如工程信息里没填施工单位）。补填工程信息后点「刷新信息」。
- **想写真正的 `#` 字符？** 目前 `#` 后跟英文字母会被当成占位符；如果文本是 `#1`、`#2` 这类（后面是数字）不受影响。确实需要时告诉我，我加 `##` 转义。
- **已经有 `cell_role` 的模板？** 占位符判定优先于普通只读判定。

## 7. 区域颜色约定

在 Excel 里用**固定填充色**标记区域，转换时翻译成单元格属性，再把颜色清回白色（避免和用户自己填的颜色冲突）：

| 标记色 | 区域 | 默认对齐 | 说明 |
|---|---|---|---|
| 无（白 `#FFFFFF`，RGB 255,255,255） | 标题区域 | 居中 | 首行合并的大标题，加粗 |
| `#D9D9D9`（RGB 217,217,217） 淡灰 | 只读区域 | 左 | 固定说明文字，双击可解锁 |
| `#FFF2CC`（RGB 255,242,204） 淡黄 | 工程信息 | 左 | 写占位符（`#projectName` 等）或工程信息标签 |
| `#DDEBF7`（RGB 221,235,247） 淡蓝 | 汇总区域 | 居中 | 评价/合格率等，后续由计算写入 |
| `#E2EFDA`（RGB 226,239,218） 淡绿 | **时间区域** | 居中 | 日期、签字日期等，格式 `yyyy-MM-dd` |
| 白色 | 填写区域 | 居中 | 用户自己填 |

> 选色方式：Excel「其他颜色 → 自定义」里直接填上面的 RGB 值，与模板保持一致；白色即 RGB 255,255,255。

约定：

- 一个格子的颜色只表达「区域 + 默认对齐」，**不要用它表达业务含义**；
- 时间区域转换后写入 `cell_role = 'date'`（复用现有列，不新增字段）；
- 时间区域双击时弹出日期选择器（`fluent::date_time::DatePicker`），选中后按 `yyyy-MM-dd` 写入单元格；未实现前先按普通可编辑处理；
- 签字区域属于「只读 + 手写签字」，用淡灰标记，后续可扩展到附件/手写。
